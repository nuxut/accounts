# Security policy

Nuxut runs as part of your desktop session and handles passwords (lock screen, polkit,
network secrets) and account tokens. We take security reports seriously.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

1. **Preferred:** use GitHub's private vulnerability reporting. Open the **Security** tab of
   the affected repository and choose **Report a vulnerability**. The report stays private
   between you and the maintainers until a fix is published.
2. **Fallback:** if you cannot use GitHub, email **hakan@goksu.me** with "Nuxut security" in
   the subject.

Include the affected repository and version (commit), steps to reproduce and the impact you
expect. You will get an answer within a few days. Once a fix is released we are happy to
credit you, unless you prefer to stay anonymous.

## Supported versions

Nuxut is pre-release; only the latest `main` branch receives fixes.
