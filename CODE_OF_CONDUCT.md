# Code of conduct

Be kind and respectful. We want Nuxut to be a welcoming project for everyone, regardless of
experience, background or identity.

- Assume good intent and keep discussions about the work, not the person.
- No harassment, insults, discriminatory language or unwelcome personal attention.
- Disagree constructively; explain your reasoning.

Maintainers may remove comments, close issues or block participants that do not follow these
rules. Report problems privately to the address in [SECURITY.md](SECURITY.md).

This code of conduct is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/).
